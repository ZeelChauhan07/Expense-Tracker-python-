# Expense Tracker (Python)

## Overview

Expense Tracker is a simple command-line application built using Python that helps users record and manage their daily expenses. It allows users to add, view, update, delete, and summarize expense records while storing data locally for future use.

## Features

* Add new expense records
* View all recorded expenses
* Update existing expense records by replacing the selected data with new details
* Delete expense entries
* Store data using file handling
* Generate expense summaries

## Tech Stack

* Python
* File Handling
* Functions
* Loops & Conditional Statements

## How to Run

1. Clone the repository.
2. Open the project folder in your preferred IDE or terminal.
3. Run the Python file:
   python ExpenseTracker.py
4. Follow the on-screen menu to manage your expenses.
5. The menu supports the following actions:
   1. Add Expense
   2. View Expenses
   3. Update Expense
   4. Delete Expense
   5. View all details
   6. Exit
